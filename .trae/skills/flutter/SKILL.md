# Flutter & Dart Skills

This skill collection provides a set of Flutter and Dart development workflows and best practices. Each sub-skill is a standalone guide for a specific task.

## Available Skills

| Skill File | Description |
| --- | --- |
| `dart-add-unit-test.md` | Write and organize unit tests for functions, methods, and classes using `package:test` |
| `dart-run-static-analysis.md` | Execute `dart analyze` to identify warnings and errors, and use `dart fix --apply` to automatically resolve mechanical lint issues |
| `dart-use-pattern-matching.md` | Use switch expressions and pattern matching with Dart 3's sealed classes, records, and destructuring |
| `flutter-add-widget-test.md` | Implement component-level tests using `WidgetTester` to verify UI rendering and user interactions |
| `flutter-apply-architecture-best-practices.md` | Architect Flutter applications using the recommended layered approach (UI, Logic, Data) |
| `flutter-build-responsive-layout.md` | Use `LayoutBuilder`, `MediaQuery`, or `Expanded`/`Flexible` to create adaptive layouts |
| `flutter-fix-layout-issues.md` | Fix Flutter layout errors (overflows, unbounded constraints) using diagnostic workflows |
| `flutter-implement-json-serialization.md` | Create model classes with `fromJson`/`toJson` methods using `dart:convert` |
| `flutter-setup-declarative-routing.md` | Configure `MaterialApp.router` with `go_router` for URL-based navigation and deep linking |
